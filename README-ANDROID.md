# HIMED Gestion – Android Studio

Projet Android Studio pour l'application WNC.

## Ouvrir
1. Ouvrir le dossier du dépôt dans Android Studio.
2. Attendre la synchronisation Gradle.
3. Lancer l'application sur un téléphone ou un émulateur.
4. Pour créer l'APK : Build > Build APK(s).

L'application charge l'interface web depuis app/src/main/assets/index.html et conserve les données avec localStorage du WebView.
